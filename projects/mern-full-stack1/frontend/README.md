# MERN Full Stack 1 frontend

Responsive React dashboard for the MERN Full Stack 1 admin API.

## Development

From this directory, copy `.env.example` to `.env`, install dependencies, and run `npm start`. The client defaults to `http://localhost:1198` for the API.

Set `REACT_APP_API_URL` to the deployed API origin when building for production. Configure the API's `CLIENT_ORIGIN` to the exact frontend origin and set secure cookie options for the deployment.

See the [project README](../README.md) for API setup, admin enrollment, environment variables, and route details.
